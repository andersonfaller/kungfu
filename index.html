Linguagem de notação para Kung Fu

Tàolù v0.1

Escreva um kati como quem escreve código: bases, passos, mãos e pernas, um movimento por linha, com colchetes para as repetições. O texto vira uma leitura numerada e pode ser traduzido para inglês e chinês.

A ideia

À esquerda, três linhas de Tàolù. À direita, o que elas dizem, movimento por movimento. Troque a língua no alto para ver o mesmo kati em inglês ou chinês.

uma linha = um tempo

Cada linha é um movimento do kati, contado em voz alta na aula.

+ junto · , depois

O sinal + liga o que acontece ao mesmo tempo. A vírgula separa o que vem em seguida, ainda no mesmo tempo.

[ … ] x3 alt

Colchetes repetem um trecho. Com alt, a repetição troca os lados: a 2ª vez sai espelhada.

Experimente

Escreva ou altere à esquerda. A leitura e as traduções se atualizam enquanto você digita, e os erros apontam a linha. Na aba Passo a passo, um boneco executa cada movimento.


          
        

        

        
    
      
    
      
    
        
    
          
    
            
    
              
            
    
            
          
    
          
    
        
    
      
    
    
    
  
    

  
    
    
    
      
    Guia
    
      
    Oito conceitos cobrem a linguagem inteira. Cada exemplo abaixo é lido pelo mesmo interpretador do editor.
    
    
    
    
    
      
    
        
    1Um movimento por linha
    
        
    
          
    Cada linha é um tempo do kati. Dentro dela você lista as ações: a base, o que as mãos fazem, o que as pernas fazem, para onde se olha.
    
          
    + junta ações simultâneas. A vírgula separa o que vem em seguida, ainda no mesmo tempo: na 2ª linha, o pé avança e só depois o corpo chega na base do arco com o soco.
    
        
    
        
    
      
    
      
    
        
    2Lado, altura e direção
    
        
    
          
    D e E dizem qual mão, perna ou pé faz a ação. Nas bases, o lado indica uma perna específica: no arco é a perna da frente, na base baixa é a perna estendida. A tabela do vocabulário mostra a regra de cada termo.
    
          
    alto, médio e baixo dão a altura do golpe. frente, trás, esquerda e direita (ou as setas ↑ ↓ ← →) dão a direção, sempre em relação ao peito naquele momento. gira 180 D vira o corpo 180 graus para a direita.
    
          
    Numa base, a direção diz para onde aponta a perna do lado indicado, e o corpo vira para lá: arco E esquerda vira o corpo para a esquerda e entra na base do arco com a perna esquerda à frente.
    
        
    
        
    
      
    
      
    
        
    3Repetição
    
        
    
          
    [ … ] x4 repete o trecho entre colchetes quatro vezes. Com alt, cada repetição troca os lados: D vira E, esquerda vira direita. É assim que se escreve uma linha do Tantui que vai alternando as pernas.
    
          
    Um movimento sozinho pode levar o x8 direto no fim, sem colchetes.
    
        
    
        
    
      
    
      
    
        
    4Nomes para trechos que voltam
    
        
    
          
    def nome { … } guarda um trecho com um nome. @nome executa o trecho naquele ponto, e @nome espelho executa do outro lado. Serve para aberturas, fechamentos e combinações que aparecem várias vezes.
    
        
    
        
    
      
    
      
    
        
    5Força, ritmo e respiração
    
        
    
          
    No fim da linha: ! marca força explosiva (發力 fā lì), ~ marca movimento lento e suave, * marca o grito (com o texto opcional), … marca uma pausa e segura 30s mantém a posição. inspira e expira entram como ações.
    
        
    
        
    
      
    
      
    
        
    6Nome da postura, texto livre e lacunas
    
        
    
          
    Um texto entre aspas no fim da linha dá nome à postura. No começo de uma ação, o texto entre aspas vira uma ação livre, para o que não está no vocabulário. ? marca um movimento que você ainda vai descrever, e ele aparece em vermelho na leitura.
    
        
    
        
    
      
    
      
    
        
    7Estrutura
    
        
    
          
    kati "Nome" { … } abre uma forma. Dentro dela, parte e linha dividem o kati, e campos como chinês:, estilo: e nota: guardam informações. Para exercícios e alongamentos use rotina; para listas numeradas, como os socos e chutes da graduação, use sequência com técnica 1, técnica 2…
    
          
    Tudo depois de # é comentário. Números no começo da linha, como 1., são ignorados: a leitura numera sozinha.
    
        
    
        
    
      
    
      
    
        
    8Três línguas
    
        
    
          
    Cada termo tem nome em português, inglês e chinês, e o interpretador aceita os três, até misturados. Também aceita pinyin sem acentos, como mabu e gongbu. Em chinês o lado vem colado antes do termo, como se escreve nos manuais: 右弓步.
    
          
    Comentários, nomes de postura e textos livres ficam como foram escritos: são suas palavras, não termos da linguagem.
    
        
    
        
    
      
    
      
    
        
    9Passo a passo com o boneco
    
        
    
          
    No editor, a aba Passo a passo executa o código um movimento por vez. Um boneco mostra a base, a posição de cada mão e de cada perna, para onde o corpo está virado e para onde se olha. Ações separadas por vírgula aparecem em sequência dentro do mesmo tempo, e a linha do código em execução fica marcada.
    
          
    Traço escuro é o lado direito e cinza é o lado esquerdo. O que muda em cada movimento aparece na cor da sua família. O boneco é um esboço da estrutura do movimento e não substitui o professor.
    
        
    
        
    
        
    
      
    
    
    
  
    

  
    
    
    
      
    Vocabulário
    
      
    Os termos que o interpretador conhece, por família. A coluna da língua escolhida no alto fica destacada.
    
    
    
    
    
      
      
    
    
    
    
    
    
  
    

  
    
    
    
      
    Exemplos
    
      
    O Wǔ Bù Quán está escrito do começo ao fim. O Tantui, o 1º Shaolin e os socos e chutes da graduação são modelos para preencher: a estrutura está pronta e cada ? é um movimento que você ainda vai descrever.
    
    
    
    
    
    
    
  
    

  
    
    
    
      
    Gramática
    
      
    A definição formal, para quem quiser escrever um interpretador ou conferir um caso difícil.
    
    
    

    programa    = { item | bloco | def } ;
bloco       = tipo [ número ] [ texto ] "{" { campo | item | bloco | def } "}" ;
tipo        = "kati" | "rotina" | "sequência" | "parte" | "linha" | "técnica" ;
def         = "def" nome "{" { item } "}" ;
campo       = nome ":" ( texto | palavras ) ;

item        = repetição | chamada | movimento ;
repetição   = "[" { item } "]" vezes ;
chamada     = "@" nome [ "espelho" ] [ vezes ] ;
vezes       = ( "x" número [ "alt" ] ) | "alt" ;

movimento   = grupo { "," grupo } { ajuste } [ texto ] ;
grupo       = ação { "+" ação } ;
ação        = termo { lado | altura | direção | número }
            | texto                         (* ação livre *)
            | "?" ;                         (* a descrever *)
ajuste      = "!" | "~" | "…" | "*" [ texto ] | [ "segura" ] tempo | vezes ;

lado        = "D" | "E" ;                   (* en: R L · 中文: 右 左 *)
altura      = "alto" | "médio" | "baixo" ;
direção     = "frente" | "trás" | "esquerda" | "direita" | "↑" | "↓" | "←" | "→" ;
tempo       = número ( "s" | "min" ) ;
texto       = '"' { caractere } '"' ;
comentário  = "#" { caractere } fim-de-linha ;
separador   = fim-de-linha | ";" ;
    
    
    
      
    Os termos são palavras de uma lista fechada, o vocabulário acima. Uma palavra desconhecida vira erro, com sugestão quando parece um erro de digitação. O que não estiver no vocabulário entra como texto entre aspas.
    
      
    O espelho troca D com E e esquerda com direita, inclusive dentro de trechos chamados com @. Espelhos se combinam: um trecho espelhado dentro de uma repetição com alt volta ao lado original na 2ª vez.
    
      
    Os arquivos da linguagem ficam na raiz do repositório: taolu.js é o interpretador (funciona no navegador e no Node), exemplos.js guarda os exemplos desta página e boneco.js calcula e desenha as poses do passo a passo. A extensão sugerida para arquivos de kati é .taolu.
